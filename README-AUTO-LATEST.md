# อัปเดต UX: เปิดรายงานล่าสุดอัตโนมัติ + ประวัติวันที่

ชุดนี้เป็น **แพตช์อัปเดต** สำหรับ GitHub โปรเจกต์ NongBuaLamphu-Budget-Dashboard ที่ติดตั้งชุดผลเบิกจ่าย + Excel Import แล้ว ไม่ใช่โปรเจกต์เต็ม

## แก้ปัญหา
- `/admin/disbursement`: เข้าสู่ระบบแล้วเปิด **รายงานล่าสุดที่บันทึกใน Supabase** อัตโนมัติ รวมฉบับร่าง; มีรายการวันย้อนหลังทั้งหมดให้กดโดยไม่ต้องจำวันที่
- หากยังไม่มีรายงานใน Supabase จะแสดงข้อความตรง ๆ และยังสามารถโหลดข้อมูลตัวอย่าง 10 พ.ย. 2569 หรืออัปโหลด Excel ได้
- `/`: เปิด **รายงานที่เผยแพร่ล่าสุด** อัตโนมัติ ไม่ล็อกที่ 10 พ.ย. 2569; ยังคงเลือกวันที่ย้อนหลังได้
- `/api/admin/disbursement?mode=list` เพิ่มรายการวันที่ที่บันทึกแล้ว (จำกัด 100 รายการ) โดยตรวจสิทธิ์ admin ก่อน
- `/api/admin/disbursement` (ไม่ส่ง date) อ่านรายงานล่าสุด; ส่ง date จึงอ่านฉบับที่ระบุ

## ติดตั้ง
1. แตก ZIP และนำไฟล์ภายในอัปโหลดทับ **path เดิม** ใน GitHub (branch `main`):
   - `components/DisbursementAdmin.tsx`
   - `components/DisbursementDashboard.tsx`
   - `app/api/admin/disbursement/route.ts`
   - `app/disbursement.css`
2. รอ Vercel Deploy เป็น Ready (ไม่ต้องปรับ SQL หรือ Environment Variables)
3. เปิด `/admin/disbursement` ลงชื่อเข้าใช้ รายงานบันทึกล่าสุดจะแสดงทันที; ทดลองกดวันที่ในประวัติ
4. เปิด `/` ทดสอบว่าแสดงรายงาน **ที่เผยแพร่ล่าสุด** อัตโนมัติ

## ข้อควรทราบ
- ถ้าข้อมูลเคยอยู่แค่ในไฟล์ตัวอย่าง / ยังไม่กด **บันทึกฉบับร่าง** จะไม่ปรากฏในประวัติ เพราะไม่มีรายการในฐานข้อมูลจริง
- ถ้ายังไม่เผยแพร่รายงานใด หน้าสาธารณะจะยังไม่เห็นข้อมูล ขณะผู้ดูแลเปิดดูฉบับร่างย้อนหลังได้
- การดึงข้อมูลรายงานย้อนหลังจากหน้าเว็บสาธารณะใช้วันที่เป็น cutoff จึงแสดงฉบับที่เผยแพร่ล่าสุดที่ไม่เกินวันที่เลือก
- ไม่เปลี่ยน Supabase schema, API บันทึก, ระบบจัดสรรเดิม หรือข้อมูลที่อยู่ในฐานข้อมูล
