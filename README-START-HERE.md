# อัปเดตเว็บไซต์จังหวัดหนองบัวลำภู ปีงบประมาณ 2570 — ใช้งานง่ายขึ้น

## แก้ปัญหาอะไร
- `/` แสดงข้อมูลจาก Excel วันที่ 10 พ.ย. 2569 ทันที แม้ยังไม่มีข้อมูลเผยแพร่ใน Supabase แต่จะมีป้าย **ข้อมูลอ้างอิง ยังไม่รับรองเผยแพร่** (ไม่ปลอมว่าเป็นข้อมูลที่อนุมัติแล้ว)
- `/admin` เป็นหลังบ้านหลักที่ล็อกอินและดูผลเบิกจ่าย พร้อมบันทึกระดับกิจกรรมย่อยได้ทันที ไม่ต้องเลือกวันที่/โหลดข้อมูลที่กระจัดกระจาย
- `/admin/disbursement` และ `/admin/monitor` ย้ายไป `/admin` อัตโนมัติ (ไม่ต้องเข้าหลายหน้า)
- `/admin/allocation` เก็บหน้าจัดสรรงบประมาณเดิม
- ปุ่ม 'เผยแพร่ผลล่าสุดสู่หน้าบ้าน' ใน `/admin` จะคำนวณรายงานจากฐานกิจกรรมย่อยและรายการเบิกเพิ่ม ไม่ใช่นับยอดซ้ำ แสดงผลที่ `/`

## ติดตั้ง (ต้องทำตามลำดับ)
1. สำรองโค้ดและ Supabase ก่อนเริ่ม อัปโหลด **ไฟล์ภายใน ZIP** ทับตำแหน่งโฟลเดอร์เดิมใน GitHub อย่าลบไฟล์อื่น
2. ที่ Supabase SQL Editor หากไม่เคยรัน `supabase/monitor.sql` ให้รันก่อน (ชุดนี้มีไฟล์ SQL ให้ครบ)
3. รัน `supabase/seed-latest.sql` อีกครั้งเพื่อเติมข้อมูลตั้งต้นในฐานข้อมูล หากข้อมูลเดิมมีแล้ว SQL จะ **ไม่เขียนทับ** และไม่เพิ่มยอดซ้ำ
4. ตรวจว่าใน Supabase มีตาราง `disbursement_reports` จาก `supabase/disbursement.sql` อยู่แล้ว ถ้ายังไม่มี ให้รัน `supabase/disbursement.sql`
5. เมื่อ Vercel Deploy เป็น Ready ให้เปิด `/` จะเห็นข้อมูล Excel ล่าสุดพร้อมป้ายอ้างอิง และ `/admin` จะเป็นศูนย์เบิกจ่ายหลัก
6. ล็อกอินด้วยบัญชีเจ้าหน้าที่เดิม หาก SQL เติมข้อมูลแล้ว รายกิจกรรมจะแสดงทันที เลือกกิจกรรมย่อยเพื่อเพิ่มการเบิกจ่ายใหม่และดูรายวัน/เดือน/ปี
7. ตรวจยอด แล้วกด 'เผยแพร่ผลล่าสุดสู่หน้าบ้าน' รายงานจะบันทึกลง `disbursement_reports` และปรากฏเป็นรายงานเผยแพร่บนหน้า `/`

## ข้อควรทราบ
- ฐานวันที่ 10 พ.ย. 2569 เป็นยอดสะสมตั้งต้น ห้ามลงเป็นรายการเบิกเพิ่มซ้ำ
- หน้าสาธารณะเมื่อยังไม่มีการเผยแพร่จะแสดง **ข้อมูลตั้งต้นแบบมีป้ายเตือน** ไม่ใช่การรับรองข้อมูลราชการ
- การกดเผยแพร่ต้องตรวจสอบรายการเบิกที่ลงใน Supabase ให้ถูกต้องทุกครั้ง
- ยังไม่มีการเชื่อมต่อบัญชี Vercel ใหม่โดยตรงจาก ChatGPT ต้อง Commit ไฟล์ใน GitHub และรัน SQL ด้วยบัญชีของคุณ
- แพตช์นี้ยังไม่ผ่านการทดสอบ Deploy จริงในบัญชี Vercel ใหม่
