# ระบบติดตามผลการเบิกจ่ายงบประมาณจังหวัดหนองบัวลำภู ปี 2570

## หน้าใช้งานหลัก
- `/` รายงานผลการเบิกจ่ายสาธารณะ แสดงยอดเผยแพร่ล่าสุด พร้อมรายโครงการ/กิจกรรม และส่งออก CSV/PDF
- `/admin` เข้าสู่ระบบเจ้าหน้าที่ 1 ครั้ง แล้วดูรายงานรายวัน/รายเดือน/รายปี บันทึกยอดเบิกเพิ่มของกิจกรรมย่อย ตรวจประวัติและเผยแพร่รายงาน
- URL หลังบ้านรุ่นเก่าจะ Redirect ไปยัง `/admin` โดยอัตโนมัติ ส่วน `/allocation` ไปที่ `/`

## หลักการทำงาน
ตั้งต้นจากบัญชี ณ 10 พฤศจิกายน 2569: งบประมาณ 52,744,500 บาท เบิกจ่ายสะสม 833,463 บาท คงเหลือ 51,911,037 บาท
ชื่อโครงการ กิจกรรม และวงเงินเป็นข้อมูลหลัก ส่วนเจ้าหน้าที่กรอกเฉพาะธุรกรรมเบิกจ่ายใหม่ตามวันที่
**ไม่บวกยอดตั้งต้น 833,463 เป็นยอดเบิกจ่ายใหม่ของวันที่ 10 พฤศจิกายน 2569** และไม่มีประวัติธุรกรรมย้อนหลังรายวันก่อนวันตั้งต้น

## ระบบและความปลอดภัย
Next.js 16 + Supabase Auth + RLS + Server API. ใช้ Environment Variables `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` ใน Vercel
ข้อมูลสาธารณะอ่านเฉพาะรายงานที่เจ้าหน้าที่เผยแพร่ หากยังไม่มีรายงานเผยแพร่จะแสดงข้อมูล Excel ตั้งต้นพร้อมคำเตือนชัดเจน
ห้ามนำ Secret Key ไปใส่ GitHub และห้ามลบฐานข้อมูลเพื่ออัปเดตเวอร์ชันเว็บไซต์

## ตั้งค่าบัญชีใหม่ (เฉพาะกรณีเริ่มติดตั้งตั้งแต่ต้น)
รัน `supabase/schema.sql` สำหรับตาราง admin_users, `supabase/monitor.sql` สำหรับกิจกรรม/ธุรกรรม และ `supabase/disbursement.sql` สำหรับ snapshot สาธารณะ
จากนั้นสร้างผู้ใช้ Supabase Auth และเพิ่มสิทธิ์ใน admin_users ตาม README เวอร์ชันแรก หากติดตั้งแล้วไม่ต้องรันซ้ำ
เข้าหน้า `/admin` แล้วคลิกนำเข้าข้อมูลตั้งต้นครั้งแรก **เฉพาะเมื่อยังไม่มีข้อมูลกิจกรรมในฐานข้อมูล**
