# ศูนย์รายงานผลการเบิกจ่ายงบประมาณ จังหวัดหนองบัวลำภู ปีงบประมาณ พ.ศ. 2570

## จุดประสงค์
เจ้าหน้าที่ปรับยอดเบิกจ่าย **รายกิจกรรมย่อย** เมื่อหน่วยงานส่งเบิก แล้วออกรายงาน **รายวัน รายเดือน และรายปี** โดยระบบคำนวณยอดสะสม งบคงเหลือ และสรุปรายโครงการให้อัตโนมัติ

## เหลือเพียง 2 หน้า
- `/` — Dashboard สาธารณะ (แสดงยอดที่เผยแพร่; ก่อนเผยแพร่แสดงยอดอ้างอิงจาก Excel พร้อมคำเตือน)
- `/admin` — ล็อกอินเจ้าหน้าที่เพียงจุดเดียว, รายงานผู้บริหาร, ดูกิจกรรมย่อย, บันทึก/แก้ไขรายการเบิกใหม่, ประวัติ, เผยแพร่ยอดล่าสุด

## การเริ่มใช้งาน
1. ใช้ Supabase เดิมและ 3 Environment Variables เดิม (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`). ห้ามใส่ secret ใน GitHub
2. ต้องรัน `supabase/schema.sql` (Auth admin), `supabase/monitor.sql` (กิจกรรมและธุรกรรม), `supabase/disbursement.sql` (รายงานสาธารณะ) ใน Supabase เดิมก่อน หากยังไม่เคยรัน; อย่ารัน schema กับฐานอื่นโดยไม่ตรวจสอบ
3. `/admin`: ถ้ายังไม่มีโครงสร้างกิจกรรม กด **นำเข้ารายการโครงการและกิจกรรมย่อย** ครั้งเดียว. ยอดตั้งต้น ณ 10 พ.ย. 2569 คือเบิกสะสม 833,463 บาท อย่าบันทึกยอดนี้ซ้ำเป็นรายการเบิกใหม่
4. เมื่อหน่วยงานส่งเบิก: เลือกกิจกรรมย่อย กรอก **ยอดเบิกเพิ่ม** กับวันที่เบิกจ่ายและเลขที่เอกสาร แล้วบันทึก
5. ตรวจยอด และกด **เผยแพร่ผลล่าสุดสู่หน้าบ้าน** เพื่อให้ `/` แสดงข้อมูลที่ยืนยันแล้ว
6. คลิก รายวัน/รายเดือน/รายปี เพื่อออกรายงานผู้บริหาร; การพิมพ์ PDF ใช้ฟังก์ชัน Print/Save as PDF ของเบราว์เซอร์

## ข้อมูลและข้อจำกัด
- งบประมาณตั้งต้น 52,744,500 บาท; เบิกจ่ายสะสม ณ 10 พ.ย. 2569 833,463 บาท; คงเหลือ 51,911,037 บาท
- รายการเบิกที่เพิ่มหลังวันที่ 10 พ.ย. 2569 เป็น transaction แยก ไม่ใช่การเขียนทับยอดตั้งต้น
- ยังไม่สามารถสร้างรายละเอียดเบิกจ่ายจริงของวันก่อนฐานวันที่ 10 พ.ย. 2569 เพราะ Excel ต้นทางให้ยอดสะสม ไม่ได้ให้ธุรกรรมทุกรายวัน
- หากรายงานเดิมยังไม่ถูกเผยแพร่ Dashboard สาธารณะจะแสดงค่าอ้างอิงพร้อมป้ายเตือน ไม่แอบอ้างว่าเป็นข้อมูลทางการที่อนุมัติ
- **อย่าลบตาราง Supabase เดิม** ระหว่าง cleanup; รายการเก่าจะอยู่ใน DB แต่ไม่ได้เป็นหน้าหลักอีกต่อไป
- Route `/admin/allocation`, `/allocation`, `/admin/disbursement`, `/admin/monitor` ถูกเอาออกด้วยชุด cleanup; URL เก่าอาจแสดง 404 ถือเป็นการถอดหน้าที่ไม่ใช้งานออกโดยตั้งใจ

## การดูแลโปรเจกต์
- เก็บเฉพาะไฟล์ Next.js ที่จำเป็นกับหน้าใหม่ และไฟล์ SQL schema ที่ใช้งานจริง
- โค้ด cleanup ไม่เปลี่ยน `package.json`, `package-lock.json`, `supabase/*.sql` หรือข้อมูลที่เคยบันทึกในฐานข้อมูล
- สคริปต์ `APPLY-CLEANUP.ps1` เป็นเครื่องมือสำหรับผู้ดูแลระบบ ไม่ต้องนำเข้าเว็บและไม่ควรเก็บใน Repository เมื่อเสร็จ
