# Budget Control Center — ระบบเบิกจ่ายรายวัน/เดือน/ปี (Patch)

ใช้กับ Repository เดิม `nongbualamphuannualreport/NongBuaLamphu-Budget-Dashboard` **ไม่ใช่โปรเจกต์ Next.js แบบติดตั้งเดี่ยว**

## เป้าหมาย
- ข้อมูลโครงการและกิจกรรมย่อยเป็นฐานข้อมูลคงที่ ใช้ยอดตามเอกสาร 10 พ.ย. 2569 เป็น **ยอดตั้งต้น** (52,744,500 บาท, เบิกจ่ายสะสม 833,463 บาท)
- เจ้าหน้าที่บันทึก **ยอดที่เบิกเพิ่มจริงตามวันที่** ที่ระดับกิจกรรมย่อย 1 รายการต่อการเบิกครั้งหนึ่ง พร้อมเลขเอกสาร ไม่ต้องคัดลอกยอดสะสมหรือทำ Excel รายวันใหม่
- เลือกรายวัน/เดือน/ปี เพื่อดูยอดเบิกใหม่ในงวด และยอดสะสม ณ วันสิ้นงวด พร้อมยอดคงเหลือ; เลือกวันที่ย้อนหลังจากประวัติได้
- สามารถแก้ไขและลบการเบิกจ่ายที่กรอกผิด และมีบันทึก audit; ใช้บัญชี Supabase เดียวกับ `/admin`
- กดปุ่ม **พิมพ์ / บันทึก PDF** จากเบราว์เซอร์สำหรับส่งผู้บริหาร โดยไม่ต้องทำ Artwork ใหม่

## วิธีติดตั้ง
1. **สำรอง Repository และฐานข้อมูลก่อน** แล้วแตก ZIP จากนั้นคัดลอกไฟล์ไปยัง root Repository เดิม ตำแหน่งโฟลเดอร์ให้ตรง (เขียนทับเฉพาะ `app/admin/page.tsx` ซึ่งเป็นตัวเพิ่มลิงก์เมนู; ไฟล์อื่นเป็นของใหม่)
2. ใน Supabase โปรเจกต์เดิม เปิด SQL Editor แล้วรัน `supabase/monitor.sql` **หนึ่งครั้ง** (เป็น additive migration ไม่ลบข้อมูลเดิม)
3. Commit ขึ้น GitHub แล้วรอ Vercel Deploy เป็น `Ready` โดยใช้ Environment Variables เดิม
4. เข้าสู่ระบบครั้งเดียวผ่าน `/admin` แล้วกดเมนู **รายงานเบิกจ่ายรายวัน / เดือน / ปี** เพื่อเข้า `/admin/monitor`
5. ครั้งแรกกด **นำเข้ารายการโครงการและกิจกรรมย่อย** ระบบนำเข้าข้อมูลฐานต้น ณ 10 พ.ย. 2569; กดได้เพียงครั้งเดียว
6. เมื่อมีใบเบิกจากหน่วยงาน ให้เลือกกิจกรรมย่อย วันที่เบิก จำนวนเงินที่ **เบิกเพิ่ม** และเลขอ้างอิง แล้วกดบันทึก
7. เลือกแท็บรายวัน รายเดือน หรือรายปี; เลือกช่วงวันที่ที่ต้องการ; กดพิมพ์หรือบันทึก PDF

## ข้อควรระวังในการใช้งานจริง
- **ห้ามเพิ่มยอด 833,463 บาทซ้ำอีก** เพราะระบบตั้งเป็นยอดสะสม ณ 10 พ.ย. 2569 แล้ว
- รายงานย้อนหลัง **ก่อน 10 พ.ย. 2569 ทำไม่ได้อย่างถูกต้อง** จากไฟล์ที่มี เพราะไม่มีประวัติรายการแต่ละวันก่อนหน้า
- รายงานรายวันมี 2 ค่าต่างกัน: `ยอดเบิกใหม่ในวันที่เลือก` และ `ยอดเบิกสะสม ณ วันนั้น` อย่าสับสน
- `ยอดเบิกสะสม` ที่แสดงในรายงานรายเดือนและรายปีเป็นยอด ณ สิ้นงวด ไม่ใช่ผลบวกสะสมทุกวัน
- การแก้ไขยอดย้อนหลังจะมีผลกับรายงานของวันนั้นและวันหลังจากนั้น ซึ่งถูกต้องตามหลักรายการสะสม
- ระบบนี้เป็น **แดชบอร์ดภายใน** ไม่เผยแพร่ข้อมูลแบบอัตโนมัติไปยังหน้าเว็บสาธารณะเดิม คุณต้องตรวจรายงานและรับรองก่อนนำไปเผยแพร่
- จำนวนรายการธุรกรรมในหน้า API จำกัด 3,000 รายการและจะแจ้งเตือนเมื่อถึงขีดจำกัด; หากมีการใช้งานเกินจำนวนนี้ควรเพิ่ม server-side pagination ก่อนใช้งานต่อ
- ไม่มีระบบอนุมัติหลายชั้นหรือ export PDF พร้อมตราครุฑ/ลายเซ็นทางราชการ; การพิมพ์ใช้ Print to PDF ของเบราว์เซอร์
- การบันทึก/แก้ไข/ลบตรวจสิทธิ์ admin บนเซิร์ฟเวอร์ ใช้ service_role เฉพาะฝั่งเซิร์ฟเวอร์

## การคำนวณ
- งบประมาณ = ผลรวมวงเงิน **กิจกรรมย่อย** + เงินเหลือจ่ายแยกเป็นหมวดที่ไม่รับการเบิก
- ยอดเบิกสะสม ณ วันรายงาน = ยอดตั้งต้น 10 พ.ย. 2569 + ผลรวมยอดที่เบิกเพิ่มนับถึงวันรายงาน
- เบิกจ่ายในงวด = ผลรวมยอดที่เบิกเพิ่มระหว่างวันต้นงวดและวันสิ้นงวด (ไม่รวมยอดตั้งต้น)
- คงเหลือ = งบประมาณ - ยอดเบิกสะสม

## หมายเหตุการนำเข้าไฟล์ Excel
ตัวนำเข้าไฟล์ Excel เดิม `/admin/disbursement` ยังอยู่และไม่ได้แก้โดย Patch นี้ แต่ระบบบันทึกยอดรายวันใหม่ที่ `/admin/monitor` ไม่ต้องอัปโหลดไฟล์ Excel ซ้ำเมื่อมีรายการเบิกใหม่ สำหรับการนำเข้าไฟล์ Excel ใหม่แทนฐานต้นต้องพัฒนาตัวเทียบส่วนต่าง/ป้องกันยอดซ้ำก่อน จึงไม่ให้ระบบนำเข้าทับฐานต้นโดยอัตโนมัติ
