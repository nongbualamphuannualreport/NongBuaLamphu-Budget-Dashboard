# อัปเดตหน้า /admin/disbursement ให้รองรับ Excel .xlsx โดยตรง

นี่คือ **แพตช์ 2 ไฟล์** สำหรับนำไปอัปโหลดทับ GitHub Repository เดิม ซึ่งติดตั้ง Dashboard ผลเบิกจ่ายฉบับก่อนหน้าแล้ว ไม่ใช่โปรเจกต์เต็มและไม่ต้องลบไฟล์อื่น

## วิธีติดตั้ง
1. แตก ZIP แล้วนำ **โฟลเดอร์ components/** และ **lib/** ภายในไปอัปโหลดทับไฟล์ในตำแหน่งเดิมของ GitHub; ห้ามอัปโหลด ZIP ทั้งก้อนเป็นไฟล์เดียว
2. มีไฟล์ที่เปลี่ยน 2 ไฟล์ คือ `components/DisbursementAdmin.tsx` และไฟล์ใหม่ `lib/import-xlsx.ts`
3. Commit ไปยัง branch ที่เชื่อม Vercel (แนะนำ Preview branch ก่อน) และให้ Vercel Deploy ใหม่
4. ไม่ต้องแก้ Supabase SQL หรือ Environment Variables หากติดตั้งชุดผลเบิกจ่ายก่อนหน้าเรียบร้อยแล้ว
5. เปิด `/admin/disbursement` เข้าสู่ระบบ กด **เลือกไฟล์ Excel (.xlsx)** เลือกไฟล์รูปแบบบัญชีผลการเบิกจ่ายของจังหวัดที่มีชีตแรกชื่อ `ผลการเบิกจ่าย`
6. ดูยอดงบประมาณ/ยอดเบิกจ่าย/คงเหลือ วันที่รายงาน จำนวนโครงการ และจำนวนกิจกรรม จากนั้น **บันทึกฉบับร่าง** ก่อน; เผยแพร่เมื่อข้อมูลถูกต้องเท่านั้น

## หลักการนำเข้า
- อ่านภายใน Browser ไม่ส่งไฟล์ Excel ต้นฉบับไปยังเซิร์ฟเวอร์ ไม่ใช้ CDN หรือ API ภายนอก
- ใช้คอลัมน์ A=ชื่อโครงการ/กิจกรรม, B=หน่วยดำเนินการ, C=งบประมาณ, E=PO, H=เบิกจ่าย, I=ใช้จ่าย, J=เงินเหลือจ่าย, K=คงเหลือ
- วันที่จาก B2 (วันที่ไทย พ.ศ. เช่น 10/11/2569 แปลงเป็น ค.ศ. 2026-11-10)
- ยอดรวมจากแถวที่ 6 และแยกแถวโครงการกับแถวกิจกรรม เพื่อไม่บวกซ้ำ; รวมเงินเหลือจ่ายเป็นรายการ RESERVE
- ตรวจสอบยอดรวมกับรายการระดับโครงการก่อนยอมรับข้อมูล หากไม่ผ่านจะแจ้งข้อความผิดพลาด
- รองรับไฟล์ขนาดไม่เกิน 8 MB; Excel .xlsx รูปแบบอื่นอาจไม่รองรับ ต้องปรับ parser ตามบัญชีต้นทาง
- **สำคัญ**: การนำเข้าไม่ได้บันทึกหรือเผยแพร่อัตโนมัติ ต้องกดบันทึกหลังล็อกอินเสมอ

## วิธีตรวจหลัง Deploy
- เปิดหน้าหลังบ้าน แล้วอัปโหลดไฟล์ `บัญชีผลการเบิกจ่ายงบจังหวัด ปี 70(1).xlsx`
- ยอดที่ควรได้จากไฟล์อ้างอิง 10 พ.ย. 2569: งบ 52,744,500 บาท, เบิกจ่าย 833,463 บาท, คงเหลือ 51,911,037 บาท
- จำนวนแถวระดับโครงการรวมเงินเหลือจ่าย 11 แถว และรายการกิจกรรม 35 แถว
- ทดสอบบันทึกฉบับร่าง โหลดข้อมูลเดิม และเช็กหน้าสาธารณะไม่แสดงฉบับร่าง

ไม่มีการเปลี่ยนระบบจัดสรรงบประมาณเดิม `/admin` หรือ `/allocation`
